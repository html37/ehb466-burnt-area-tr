## Problem

In July–August 2021 wildfires burned more than 60 000 ha around Manavgat (Antalya) and Marmaris (Muğla).
The General Directorate of Forestry (OGM) and AFAD need accurate burnt-area maps for damage assessment and
restoration planning. This repository maps the burnt area of both fires from bi-temporal Sentinel-2 L2A imagery and
compares three families of methods against the EFFIS reference perimeters on exactly the same 20 m grid.

## Contributions

1. **A lightweight transfer method.** A per-pixel LightGBM classifier (36 spectral features, CPU only) trained
   *only* on the Greek FLOGA dataset and applied unchanged to Türkiye — no Turkish data are used for training,
   threshold selection or hyper-parameter tuning.
2. **First quantitative FLOGA→Türkiye transfer test.** dNBR (USGS and FLOGA-tuned thresholds), the deep
   change-detection model BAM-CD (official weights) and our models are compared in-domain (FLOGA test split) and
   out-of-domain (Manavgat, Marmaris) with 5 seeds, spatial block-bootstrap confidence intervals, an ablation and an
   error analysis by land cover.
3. **An open, reproducible pipeline** that reads only the needed bytes of the 1.1 TB FLOGA release and runs end to
   end (`run_all.py`), with a ≤ 30 min Colab demo.

## Results (auto-generated by `scripts/95_make_paper_numbers.py`)

F1 of the burnt class. Learned models: mean ± std over 5 seeds; 95 % CI from a 1 km spatial block bootstrap
(1000 resamples). Türkiye reference: EFFIS perimeters; evaluation area: EFFIS polygon bounding box + 3 km.

## How to run

**Colab (demo, ≤ 30 min, CPU is enough):** click the badge above and choose *Runtime → Run all*. The notebook
downloads the trained LightGBM models from the `v1.0` release and the official BAM-CD weights, builds the Sentinel-2
stacks from Planetary Computer and prints metrics, maps and runtime (`docs/demo_runtime.md`).

**Local, full reproduction:**

```bash
git clone https://github.com/html37/ehb466-burnt-area-tr.git
cd ehb466-burnt-area-tr
python -m venv .venv && .venv/Scripts/activate      # Linux/macOS: source .venv/bin/activate
pip install -r requirements.txt                       # exact versions: requirements-lock.txt
python run_all.py                                     # skips finished steps; --force to redo; --list to inspect
pytest -q
```

`run_all.py` runs: external resources (`05`) → Turkish test set (`10`) → FLOGA patches/samples (`20`) → dNBR
threshold on FLOGA val (`30`) → band harmonisation check (`35`) → HPO (`40`) → final training, 5 seeds (`50`) →
BAM-CD (`60`) → Turkish predictions (`65`) → ablation models (`80 --train`) → evaluation + bootstrap (`70`) →
cost table (`72`) → ablation report (`80 --report`) → error analysis (`90`) → figures (`85`) → paper numbers (`95`).
Hardware used: `docs/hardware.md` (Ryzen 7 6800H, 16 GB RAM, RTX 3050 Ti 4 GB).

## Test isolation

Manavgat and Marmaris are only a test set. Every choice (dNBR threshold, hyper-parameters, decision thresholds,
features, early stopping) is made on the FLOGA validation split. `tests/test_no_leakage.py` asserts that the
preparation, tuning and training scripts never import or read the Turkish data.
